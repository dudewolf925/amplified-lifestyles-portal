# AMPLIFIED Safety Portal — Weekly Talk + PDF Training Demo

Upload all ZIP contents to the root of the GitHub Pages repository.

- Weekly Construction Safety Talk: checklist and acknowledgment only; **no quiz**.
- Additional Safety Training: Basic Ladder Safety PDF included as a clean 7-page training-only copy (signature and completion-certificate pages omitted).
- Manager review of 20 draft ladder questions; each technician receives 5 randomly selected questions in a pop-up after confirming review; 80% pass, randomized retakes.
- Other PDF uploads are stored only in the current browser (4 MB limit); arbitrary-PDF AI question generation is **not connected**. Such topics cannot be assigned until a question bank is prepared and approved in a future release.
- CRM meetings are fictional demonstration data; no real CRM sync, authentication, notifications, or shared compliance records.
- Existing browser data is retained using the original localStorage key; refresh after upload. For a fresh test use Settings > Reset all browser test data (deletes only local demo records).
- Do not use this demo as an official safety training or compliance record system.


## Three publishing options (updated)
1. Safety on Construction Sites: document review + ten-item safety check + acknowledgment, NO quiz.
2. Safety on Construction Sites + Safety Topic: creates two linked requirements for each selected technician, independently completed and tracked. Quiz only for the safety topic.
3. Safety Topic: training PDF + randomized five-question quiz in a modal after confirming review, no site safety checklist.

This is a browser-local demo. Meeting data is fictional; no live CRM integration, messaging, official records or AI PDF question generation.

## Installer Skills updates
- High-contrast white/gray quiz text and answer choices replace hard-to-read blue text.
- Skills > Manager: edit existing questions, all four answers, correct answer, level, domain, explanation, and active status; add questions.
- Skills > Manager: assign a skills quiz to selected technician(s), by level, question count, and due date.
- Skills > Technician: select a demo technician, view their assigned quizzes, and complete one; submitted results include an immutable question snapshot for review.
- Skills > Results: view each technician's answers and score.
- Existing browser-local demo records are migrated to a new editable skills bank without clearing prior data.
- All assignments, edits, and results are stored in the current browser only. No real authentication, cross-device synchronization, or notifications.
